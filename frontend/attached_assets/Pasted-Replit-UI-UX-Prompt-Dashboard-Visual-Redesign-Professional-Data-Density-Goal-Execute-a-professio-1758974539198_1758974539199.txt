Replit UI/UX Prompt: Dashboard Visual Redesign & Professional Data Density
Goal: Execute a professional visual and structural redesign of the main Dashboard page, focusing on high data density, clear hierarchy, and proactive presentation. The design must be robust enough to look premium and professional in both Light and Dark Themes, requiring only color palette inversion, not layout changes.

Design Principle: High-Density, Proactive Cockpit View.

1. Global Theme and Color Strategy
The application must support both themes, ensuring professionalism is maintained in both.

Element	Dark Theme Specs	Light Theme Specs	Rationale
Background	#121212 (Sophisticated Black)	#F5F7FA (Clean Off-White)	Ensures high contrast and a modern feel in both modes.
Card/Surface	#1E1E1E (Slightly lighter than background)	#FFFFFF (Pure White)	Provides depth and separation for data cards.
Primary Action	#007BFF (Vibrant Blue)	#007BFF (Vibrant Blue)	Consistent, trustworthy accent color for focus and links.
Success/Proactive	#28A745 (Vibrant Green)	#198754 (Deep Green)	Clear visual for system success and good ratings.

2. Dashboard Layout & Hierarchy Redesign
The dashboard will be restructured into distinct rows to establish a clear hierarchy, prioritizing Fleet Totals first.

A. Row 1: Fleet Totals & Financial KPIs (The Header Strip)
This row should be a dense strip of smaller, concise Insight Cards, clearly labeled as "Fleet Totals" and reflecting the current filters.

KPI (InsightCard)	Required Data & Structure	Visual Priority
Total Engine Hours (Hr)	Value (Big), Estimated Total Operating Cost ($) (Small, Secondary).	High. Must be easily legible.
Total Distance (Km)	Value (Big), Small line graph showing 7-day trend (Subtle).	High. Essential operational data.
Total Fuel Used (L)	Value (Big), Total Fuel Cost ($) (Small, Secondary).	High. Core cost intelligence.
System Reliability	Value (Big, %), Uptime Status (Text: Excellent/Good).	High. Directly addresses the need to show systems are "working well."

3. Implementation Notes for Replit
Responsiveness: All rows must reflow cleanly on smaller screens. Row 1 KPIs should stack 2 or 3 per row on mobile.

Toggle Implementation: The L/Hr graph toggle to L/100km is a required component that elevates the dashboard's professionalism.

Theming: Use CSS variables or a theming library (like Vuetify/Tailwind) to ensure a single component structure serves both the Light and Dark color palettes seamlessly.
