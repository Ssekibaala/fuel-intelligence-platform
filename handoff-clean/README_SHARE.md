## Very simple setup steps (for backend team)
1. Link Supabase project:
   - `npx supabase link --project-ref pkduhowdqvymmvboyivt`
2. In Supabase SQL Editor, run:
   - `supabase/migrations/0001_all_in_one.sql`
   - `supabase/migrations/20260226110000_drop_user_settings.sql`
   - `supabase/migrations/20260226123000_rename_daily_movement_reports_to_trip_reports.sql`
   - `supabase/migrations/20260226131000_trim_trip_reports_and_backfill_departure_date.sql`
3. Deploy function:
   - `npx supabase functions deploy process-telemetry --project-ref pkduhowdqvymmvboyivt`
4. Start API server in your full app repo (where package.json exists).

## Notes
- `0001_all_in_one.sql` is generated by combining core project migrations in order.
- `20260226110000_drop_user_settings.sql` removes the unused `user_settings` table.
- `20260226123000_rename_daily_movement_reports_to_trip_reports.sql` renames trip storage to `trip_reports`.
- `20260226131000_trim_trip_reports_and_backfill_departure_date.sql` backfills `departure_date` and removes unused trip table columns.
- This package is intentionally minimal for frontend integration handoff.
